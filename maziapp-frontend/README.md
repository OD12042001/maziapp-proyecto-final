# Maziapp (Mazi Flow)

Este proyecto se generó a partir de la copia técnica del proyecto MAZI original usando [Angular CLI](https://github.com/angular/angular-cli) versión 21.2.5.

Ver `../docs/` para la documentación de arquitectura, seguridad, autenticación, base de datos y desarrollo de **Mazi Flow**.

## Servidor de desarrollo

```bash
ng serve
```

Luego abre `http://localhost:4200/`.

## Build

```bash
ng build
```

## Tests

```bash
ng test
```
